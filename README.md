# CMOS Standard Cell Design and Characterization Using SPICE

**Technologies:** Ngspice | SKY130 PDK | CMOS | SPICE | Python

## Overview
This repository focuses on transistor-level CMOS standard-cell design and electrical characterization using the open-source SKY130 Process Design Kit (PDK) and Ngspice simulator.

The project explores the design and analysis of fundamental CMOS logic gates and their electrical performance.

## Objectives
- Understand CMOS transistor-level circuit design.
- Design basic digital standard cells.
- Perform DC and transient SPICE simulations.
- Analyze voltage transfer characteristics (VTC).
- Study timing, power consumption and noise margins.

## Standard Cells
- CMOS Inverter (INV)
- 2-Input NAND (NAND2)
- 2-Input NOR (NOR2)
- AND Gate (AND2)
- OR Gate (OR2)

## Characterization Parameters
- Voltage Transfer Characteristics (VTC)
- Propagation Delay (tpHL and tpLH)
- Rise Time and Fall Time
- Static and Dynamic Power
- Leakage Current
- Noise Margin (NMH and NML)
